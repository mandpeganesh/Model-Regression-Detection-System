# Regression Dashboard Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React dashboard for the regression system: a read-only public demo on GitHub Pages built from durable CI history (including PR runs), and a local owner mode backed by a FastAPI API that can run evals, edit golden cases and create prompt versions.

**Architecture:** One Python function, `build_snapshot`, turns `runs.db` (+ `pr-runs.db`), the golden dataset and the prompts into a single JSON document, using the existing `store` and `compare` code. The demo build reads it as a static file; the owner build reads it from `GET /api/snapshot`. Ground-truth rules (IDs, dataset version bumps, immutable prompts) live in a pure module `edits.py` that the API calls. CI keeps history on an `eval-history` branch instead of the Actions cache.

**Tech Stack:** Python 3.11+ (existing), FastAPI + uvicorn (optional `ui` extra), React + Vite + TypeScript, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-25-frontend-design.md` (approved). Mockups: `.superpowers/brainstorm/1690-1792931085/content/layout.html` (option A) and `screens.html`. `CLAUDE.md` rules stay binding.

**Branch:** `feat/frontend` (based on `feat/regression-system`, PR #1).

## Global Constraints

- Python deps: `ui = ["fastapi", "uvicorn"]` optional extra; `dev` gains `httpx` (needed by FastAPI's `TestClient`; it is **not** installed via `openai`, contrary to the spec's note). Nothing else.
- JS deps only: `react`, `react-dom`, `vite`, `@vitejs/plugin-react`, `typescript`, `@types/react`, `@types/react-dom`. No router, chart, CSS or state libraries.
- `fastapi`/`uvicorn` imported only inside `api.py` and the `serve` subcommand, so `python -m regress run` works without the `ui` extra.
- `PromptConfig`, `GoldenCase`, `GoldenDataset` and the existing `store.py` tables are unchanged (a new `pr_runs` table is added).
- Thresholds only via `Settings.from_env()`. Secrets never appear in any API response or the snapshot.
- All file I/O `encoding="utf-8"`; JSON written with `ensure_ascii=False`; YAML with `allow_unicode=True`. Paths via `pathlib`.
- The frontend never computes status, deltas, pass/fail or drift; it displays snapshot values.
- No LLM call anywhere in the edit paths. No "suggest" features.
- Owner API binds `127.0.0.1` only; write endpoints reject a non-localhost `Origin` with 403.
- Node 22 (local is v22.11.0; CI uses the same).
- Unit tests: no network, OpenAI/Slack faked as in `tests/fakes.py`.

## Review Focus

1. **Empty history** (no `runs.db`, or no `eval-history` branch yet): snapshot has `runs: []`, the site shows "No runs yet" instead of crashing. Tests in Task 2; manual check in Task 5.
2. **Non-ASCII text** (`"Ich kann mich nicht einloggen — ¿ayuda? 日本語"`) round-trips through snapshot, golden writes and prompt YAML unchanged. Tests in Tasks 2 and 3.
3. **Path traversal via prompt version** (`"../evil"`, `"v2/../../x"`): rejected before any file is written. Test in Task 3.
4. **Failed case results** (`actual_category: null`, `error: "refusal: ..."`) serialize to the snapshot and render as the error text in run detail. Test in Task 2; manual check in Task 6.
5. **A write while a run is in progress** returns 409 and leaves `data/golden.json` byte-identical. Test in Task 4.

### Task 2: Snapshot builder and `regress export`

**Files:**
- Create: `src/regress/snapshot.py`
- Modify: `src/regress/cli.py`
- Test: `tests/test_snapshot.py`, `tests/test_cli.py`

**Interfaces:**
- Consumes: `all_runs`, `list_pr_runs` (Task 1), `compare`, `detect_drift`, `Settings`, `GoldenDataset`, `PromptConfig`.
- Produces: `build_snapshot(runs: list[RunResult], pr_runs: list[tuple[RunResult, int, str]], dataset: GoldenDataset, prompts: list[PromptConfig], settings: Settings) -> dict`, and `load_prompts(prompts_dir: Path) -> list[PromptConfig]` (newest `created_at` first). JSON shape (field names are the contract for Task 5's `types.ts`):

```
{
  "generated_at": ISO-8601 UTC,
  "settings": {warn_threshold, critical_threshold, drift_threshold, drift_window, relevance_pass_min},
  "dataset": GoldenDataset.model_dump(mode="json"),
  "prompts": [PromptConfig.model_dump(mode="json"), ...],          // newest first
  "runs":    [RunView, ...],                                         // oldest first, all dataset versions
  "pr_runs": [RunView + {"pr_number": int, "head_sha": str}, ...]    // oldest first
}
RunView = {run_id, created_at, prompt_version, model, dataset_version,
           pass_rate, category_accuracy, total_tokens, mean_latency_ms,
           cases: [asdict(CaseResult)],
           comparison: {baseline_run_id, baseline_pass_rate, pass_rate_delta, category_deltas,
                        regressions: [case_id], improvements: [case_id], status},
           drift: asdict(Drift) | null}                               // null for PR runs
```

  Main runs: baseline = previous run with the same `dataset_version` in `runs`; drift over that version's pass rates up to and including this run. PR runs: baseline = the latest main run of the same `dataset_version`; `drift: null`.
- CLI: `regress export --db PATH [--pr-db PATH] [--dataset data/golden.json] [--prompts-dir prompts] --out PATH`. A missing DB file means no runs (don't create it). Exit 0 / 2 like `run`.

### Task 3: Ground-truth edit guards

**Files:**
- Create: `src/regress/edits.py`
- Test: `tests/test_edits.py`

**Interfaces:**
- Consumes: `GoldenCase`, `GoldenDataset`, `load_dataset`, `PromptConfig`, `load_prompt`, `latest_prompt`.
- Produces (all raise `ValueError` with a human-readable message on a rule break; nothing is written on error):
  - `check_version(current: str, new: str, used_versions: set[str]) -> None` — if `current in used_versions` (frozen): `new != current`. Always: `new == current or new not in used_versions`.
  - `add_case(ds: GoldenDataset, case: GoldenCase, new_version: str, used_versions: set[str], used_ids: set[str]) -> GoldenDataset` — id not in `ds` and not in `used_ids`; appended at the end; result re-validated as `GoldenDataset`.
  - `edit_case(ds: GoldenDataset, case_id: str, case: GoldenCase, new_version: str, used_versions: set[str]) -> GoldenDataset` — `case.id == case_id`; case exists (else `KeyError`); position kept.
  - `save_dataset(path: Path, ds: GoldenDataset) -> None` — `json.dumps(ds.model_dump(mode="json"), ensure_ascii=False, indent=2) + "\n"`.
  - `create_prompt(prompts_dir: Path, *, version: str, model: str, system_prompt: str, few_shot_examples: list[dict], now: datetime) -> Path` — `version` matches `^[A-Za-z0-9._-]+$` and isn't `.`/`..`; no loaded prompt has that version; `prompts_dir/<version>.yaml` doesn't exist; `created_at = now` (UTC); validated as `PromptConfig`; written with `yaml.safe_dump(..., allow_unicode=True, sort_keys=False)` and multi-line strings in `|` block style; file opened with mode `"x"` (never overwrite).

### Task 4: Owner API and `regress serve`

**Files:**

- Modify: `src/regress/cli.py`, `pyproject.toml` (`ui` extra; `httpx` in `dev`)

**Interfaces:**
- Consumes: `execute_run`, `make_client`, store helpers (Task 1), `build_snapshot`, `load_prompts` (Task 2), `edits.*` (Task 3), `Settings.from_env`.
- Produces:
  - `@dataclass AppPaths`: `dataset: Path`, `prompts_dir: Path`, `db: Path`, `out: Path`, `static_dir: Path | None`.
  - `create_app(paths: AppPaths) -> FastAPI`. The app holds one run state (`threading.Lock`-guarded) and exposes `app.state.run_thread: threading.Thread | None` so tests can `join()`.
  - Endpoints:
    - `GET /api/snapshot` → `build_snapshot(all_runs(db), [], dataset, load_prompts(...), Settings.from_env())`.
    - `POST /api/runs` body `{"prompt_version": str}` → 202 `{"run_id": null}` and starts `execute_run` in a thread with `on_case_done` updating progress; 404 unknown version; 409 if running.
    - `GET /api/runs/current` → `{"state": "idle"|"running"|"done"|"error", "done": int, "total": int, "run_id": str | null, "error": str | null}`. Errors that `run_command` maps to exit 2 become `state: "error"` with the message.
    - `POST /api/golden/cases` body `{"case": GoldenCase, "new_version": str}`; `PUT /api/golden/cases/{case_id}` same body → 200 `{"version": new_version}`. Guards get `used_dataset_versions(db)` and `used_case_ids(db)` from the local `runs.db`, then `save_dataset`. `ValueError` → 422 `{"detail": msg}`; `KeyError` → 404; run in progress → 409.
    - `POST /api/prompts` body `{"version", "model", "system_prompt", "few_shot_examples"}` → 201 `{"path": "prompts/<version>.yaml"}`; errors as above.
    - Write endpoints (all `POST`/`PUT`): `Origin` header absent, or its host is `localhost`/`127.0.0.1` (any port) — else 403.
    - If `static_dir` exists, mount it at `/` (`StaticFiles(html=True)`) after the API routes.
  - `regress serve [--port 8000] [--dataset ...] [--prompts-dir ...] [--db ...] [--out ...]`: imports `api` and `uvicorn` inside the function, `uvicorn.run(app, host="127.0.0.1", port=port)`, `static_dir=Path("frontend/dist")`. Without the `ui` extra: print "install with pip install -e .[ui]" and exit 2.
